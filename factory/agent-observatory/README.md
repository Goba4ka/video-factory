# Agent Observatory

Локальная демонстрационная карта архитектуры Video Factory. Она показывает пять тематических линий, обязательные gates и два параллельных рендера мотивационного формата. Сигналы и статусы симулируются из локальных статических данных; сайт не подключается к API и не утверждает, что показывает живые процессы.

Снимок от 29.08.2026 синхронизирован с пятью реальными Codex-чатами и шестью
готовыми артефактами. Значение `QC PASS / HOLD` намеренно разделяет техническую
готовность и отсутствие разрешения на публикацию.

## Запуск

Из этой папки:

```powershell
python -m http.server 4173
```

Откройте `http://localhost:4173`.

Можно также открыть `index.html` напрямую двойным кликом.
