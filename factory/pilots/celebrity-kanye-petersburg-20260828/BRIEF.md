# Celebrity short: Канье в Петербурге

- Формат: вертикальный новостной short, 1080×1920, 30 fps.
- Язык: только русский.
- Длительность: 25–32 секунды.
- Обещание ролику: за полминуты объяснить резкий разворот вокруг концертов Ye в Петербурге, не выдавая переговоры за окончательно подписанный контракт.
- Хук: «КАНЬЕ ВСЁ-ТАКИ ЕДЕТ В ПЕТЕРБУРГ?»
- Дуга: отмена/сомнение → ответ организатора → свежий разворот → открытый вопрос.
- Визуальный принцип: крупное лицо Ye или масштаб концерта занимает почти весь кадр; доказательные тезисы появляются по центру, без бокового UI.
- Озвучка: Fish Audio, один полный русский запрос; максимум две генерации на video_id.
- Музыка: напряжённая электронная пульсация, ниже речи с автоматическим ducking.
- Публикационный тон: быстро, доказательно, без кликбейтного утверждения там, где контракт публично не показан.
