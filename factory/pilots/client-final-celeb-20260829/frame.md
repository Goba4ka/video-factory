# Frame direction

Концепт: «дорогой редакционный скролл, который превращает звёздный инфоповод в
историю о помощи». Фотографии не прячутся в карточках: лицо — главный кадр,
поверх него лежит только короткий титр и тонкая акцентная линия.

- Фон: тёплый почти-чёрный `#0B0A0F`, без полноэкранных линейных градиентов.
- Фокус: полноэкранное фото с крупным лицом; затем короткая цифра или титр.
- Акцент: коралловый `#FF4F79`, только на одном слове или цифре.
- Типографика: Manrope 800–900 для хука/субтитров; IBM Plex Mono для чисел.
- Детали: мягкий локальный glow, крупная полупрозрачная цифра, тонкая рамка safe-zone.
- Запрещено: верхние/боковые бейджи, логотипы-водяные знаки, мелкие подписи,
  стеклянные UI-карточки, неоновые градиенты, больше двух строк субтитров.
