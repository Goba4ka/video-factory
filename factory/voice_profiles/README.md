# Golden voice profiles

Fish Audio может запускаться для narrated lanes только после двух независимых
решений: подтверждения прав на голос и художественного утверждения exact
`reference_id` по контрольному WAV. Одно не заменяет другое.

`catalog.json` — fail-closed реестр. Профиль пригоден к работе только когда:

- `state` равен `approved`;
- язык и lane входят в утверждённую область;
- сохранён SHA-256 прослушанного golden sample;
- человек отдельно подтвердил тембр, дикцию, темп и эмоциональный диапазон;
- для конкретного job существует действующий `voice_rights_approval`;
- поколение остаётся в лимите не более двух Fish-вызовов на ролик.

Rejected-профиль не может быть fallback. Сейчас в Fish workspace виден только
один русский private voice, и он отклонён владельцем. Поэтому narrated
production остаётся закрытым до добавления хотя бы одного нового
rights-cleared и quality-approved профиля.
