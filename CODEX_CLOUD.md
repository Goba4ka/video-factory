# Codex Cloud: работа с телефона

Этот репозиторий подготовлен для разработки через Codex Cloud без включённого
домашнего компьютера.

## Первичная настройка окружения

1. Откройте `https://chatgpt.com/codex` и подключите GitHub-репозиторий
   `Goba4ka/video-factory`. Репозиторий публичный, поэтому не добавляйте в него
   секреты, приватные медиафайлы или ключи API.
2. Создайте для него Cloud environment.
3. Укажите setup-команду:

   ```bash
   bash scripts/codex-cloud-setup.sh
   ```

4. Для полнофункциональной работы включите `Agent internet access = On` и
   добавьте `FISH_API_KEY` и `PEXELS_API_KEY` в раздел `Environment variables`.
   Раздел `Secrets` доступен только setup-скрипту и не передаёт значения
   в агентную фазу. Не вставляйте значения ключей в чат, логи или Git.
5. Первой задачей отправьте:

   ```text
   Прочитай AGENTS.md и factory/START_HERE.md. Убедись, что main содержит
   коммит 273bc91 или более новый. Запусти тесты и дай краткий отчёт,
   ничего не публикуя и не вызывая платные API без моей явной команды.
   ```

## Что находится в Git

- Python control plane и тесты;
- редакционные правила, JSON-схемы и role prompts;
- HyperFrames-разметка и исходники пилотов;
- отобранные пилотные аудио, изображения, thumbnails и audit-материалы;
- текстовые исследования, манифесты и QC-отчёты;
- инструкции по production-развёртыванию.

## Что намеренно не находится в Git

- готовые MP4 и промежуточные рендеры;
- крупные исходные видео и прочие игнорируемые media-архивы;
- модели Whisper/Piper и локальные бинарники;
- `node_modules`, virtualenv, кэши и временные кадры;
- SQLite runtime-state и любые секреты.

Эти материалы остаются в локальном архиве. Для полноценного облачного рендера
их нужно отдельно разместить в приватном S3-совместимом хранилище и скачивать по
манифесту. Обычный Codex Cloud не заменяет круглосуточный production-сервер или
GPU render-host.
